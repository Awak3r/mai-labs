# Проверка переноса

Дата: 2026-11-15. Среда: Linux, Git 2.43.0, CMake 3.28.3, GCC/G++.

## Целостность

- Все девять исходных `main` являются предками новой `main` (`git merge-base --is-ancestor`). Исходные SHA приведены в `MIGRATION.json`.
- Все 190 сохранённых исходных файлов побайтово сверены через Git blob SHA с оригиналами. Исходники, тесты, отчёты и данные не редактировались.
- Удалены только 795 файлов из сгенерированных каталогов сборки и ELF-исполняемых файлов. Список — в `MIGRATION.json`; старая история сохранена.
- `git fsck --full` прошёл для резервных копий и объединённого репозитория.
- У исходников на момент копирования была только ветка `main`, тегов не было. Локальные mirror-копии сохранены отдельно от публичного репозитория.

## Сборки и тесты

Для каждого из 26 `CMakeLists.txt` выполнена независимая конфигурация `cmake -S <каталог> -B <внешний-каталог-сборки>`.

- 24 конфигурации завершились успешно.
- `oop/lab04` и `oop/lab05`: конфигурация остановилась с `Could NOT find GTest`.
- Для остальных 24 выполнена `cmake --build <каталог> --parallel 2`. Полные сборки не прошли: отсутствуют `gtest/gtest.h` либо библиотеки `gtest` / `gtest_main`. Отдельные цели успели собраться, но это не успешная полная сборка.
- Google Test в окружении не установлен. Исходные конфигурации с `FetchContent_Declare` не всегда загружают его. Исправления старых CMake-файлов не входят в перенос.
- CTest не запускался: тестовые исполняемые файлы не собраны. Корректность алгоритмов не подтверждена.
- Для всех семи `.c` в `operating-systems/` выполнен `gcc -fsyntax-only -pthread <файл>` — все проверки успешны. Это не линковка и не проверка поведения программ.

После установки/подключения Google Test следует повторить полные сборки и тесты. Иные ошибки могли быть скрыты текущими ошибками зависимостей.

## Публичность

Перед публикацией во всех исторических blob-объектах выполнен базовый поиск шаблонов приватных ключей, GitHub-токенов, AWS access key ID, строковых присваиваний паролей/API-ключей и чувствительных имён файлов. Совпадений не обнаружено. Это ограниченная эвристическая проверка, не специализированный или исчерпывающий аудит секретов.

Публичная история сохраняет исходные метаданные авторов, старые пути, отчёты и трассировки. Доступность приватных исходных репозиториев не требуется для клонирования нового архива.
