## Сборка

Работы используют C/C++, Linux/POSIX и CMake. Для C++-работ требуется поддержка C++20. Многие тесты зависят от Google Test; исходные CMake-конфигурации сохранены и могут требовать установленного Google Test или дополнительной настройки. Вызов `FetchContent_Declare` в старом проекте сам по себе не устанавливает зависимость.

Каждую работу собирайте **отдельно**, из корня этого репозитория. Пример для ООП:

```sh
cmake -S oop/lab05 -B build/oop-lab05
cmake --build build/oop-lab05
ctest --test-dir build/oop-lab05 --output-on-failure
```

Для задач с собственным `CMakeLists.txt`:

```sh
cmake -S fundamentals/lab1/task1 -B build/fund-lab1-task1
cmake --build build/fund-lab1-task1
```

Не все задания имеют CMake или зарегистрированные CTest-тесты. В `operating-systems/` исходники находятся в `lab*/src`, отчёты — в `lab*/doc`, трассировки — в `lab*/trace`. Там сохранены исходные имена файлов; некоторые содержат пробелы. Универсальной команды запуска для всех работ нет. Трассировки являются учебными материалами, а не временными логами приложения.

## Организация архива

- История всех девяти исходных репозиториев включена merge-коммитами **без squash и переписывания исходных коммитов**.
- Код, тесты, входные данные, отчёты и трассировки перенесены без изменения содержимого.
- Из актуального дерева убраны сгенерированные каталоги `build/` и ELF-исполняемые файлы. Они по-прежнему доступны в старой истории; это не очистка размера Git-истории.
- Внутренние названия заданий, включая `task4Ai`, `task1ok` и `task3finshed`, сохранены, чтобы не менять старые ссылки и структуру работ без проверки.
- Это архив учебного кода, а не гарантия корректности всех реализаций или прохождения всех тестов. Статус проверки переноса — в [VALIDATION.md](VALIDATION.md).

## Происхождение и история

[MIGRATION.json](MIGRATION.json) содержит исходный SHA ветки `main` каждого репозитория, каталог назначения и список убранных генерируемых файлов. Старые коммиты сохраняют исходные пути; например:

```sh
git log --all --oneline
git log --oneline main -- oop/lab01
```

Для просмотра истории конкретного источника используйте SHA из `MIGRATION.json`: `git log <исходный-SHA>`. Фильтр по новому пути не покажет все изменения до импорта.

Исходные приватные репозитории не удалены и не архивированы. Другие проекты аккаунта в этот архив не включены. Новая общая лицензия при переносе не назначалась.
